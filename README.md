# 加点ログ (PLUSLOG)

0点が基準の完全加点方式・行動ログ PWA です。  
すべての記録・設定・カスタム効果音は端末ローカル（`localStorage` / `IndexedDB`）にのみ保存され、外部サーバーへ送信されません。

## 開発コマンド

```bash
npm install
npm run dev
npm run build
```

## ライセンス・帰属

- アプリ本体および `public/sfx/*.wav`: オリジナル作成
- `public/sfx/undo.ogg`: Google Material Design Sound Resources (CC BY 4.0)
